
# CodeAlpha Basic Chatbot

## Project Description
This is a simple rule-based chatbot developed using Python.

## Features
- Greets the user.
- Responds to basic messages.
- Handles unknown messages.
- Exits when the user types bye.
- 

## Technologies Used
- Python
- VS Code

## Concepts Used
- Input and Output
- If-elif-else statements
- While loop
- Functions

## How to Run
1. Install Python.
2. Download the project.
3. Open the terminal.
4. Run: python basic_chatbot.py
